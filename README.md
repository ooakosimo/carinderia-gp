# CARINDERIA GRAND PRIX 🏁🍲

A Filipino street circuit you can drive in your browser.
City streets → coast → volcano. There's a loop. There's a ghost. The carinderia is always open.

**Play:** https://carinderia-gp.vercel.app
**Mirror:** https://ooakosimo.github.io/carinderia-gp/

## Controls
| Key | Does |
|---|---|
| W / ↑ | gas |
| A / D | steer |
| Space / S | brake |
| C | camera |
| Q | quality |
| M | sound |
| R | restart |

## What's in v1
- drivable circuit: city, coast, volcano
- loop-the-loop
- ghost car
- pit lane
- minimap
